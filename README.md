# Littlegods Games

Littlegods Games es un launcher de escritorio construido con React, Electron y Node.js para instalar y organizar el catalogo oficial de juegos de Littlegods.

## Desarrollo

```bash
npm install
npm run dev
```

## Paquetes

```bash
npm run dist:win
npm run dist:linux
```

`dist:win` genera un instalador `.exe`. `dist:linux` genera un `.AppImage` y debe ejecutarse en Linux o en CI Linux.

Usa únicamente torrents y juegos que puedas distribuir o descargar legalmente.
